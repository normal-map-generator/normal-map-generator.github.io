Por qué usar este generador de normal map

Conjunto PBR completo, no solo el normal map

En una sola pasada obtienes el normal map junto con los mapas diffuse, roughness y metallic, así que el material entra directo en Blender, Unity, Unreal o Godot sin bakeos adicionales.

Funciona desde una foto, un tile o un modelo generado

Generador de texto 3D integrado

Escribe un prompt para crear un modelo 3D texturizado a partir de una descripción y genera sus normal maps en el mismo proyecto. Ideal para logotipos, rótulos y props de videojuegos.

Exportación a Roblox mesh y motores de juego

Descarga en GLB, FBX u OBJ con las texturas empaquetadas, incluida una malla optimizada para Roblox con un presupuesto de polígonos que se importa limpiamente en Roblox Studio.

Cómo generar un normal map

  1. Sube o genera
    Sube una imagen de textura o una foto, o escribe un prompt para crear un modelo 3D desde texto. Ambas opciones parten de la misma pantalla.
  2. Elige la resolución de textura
    Escoge 1K para previsualizaciones o hasta texturas PBR en 4K para assets principales. El generador de normal map se ejecuta en la nube, así que no hay nada que instalar.
  3. Descarga los mapas o el modelo completo
    Obtén los mapas normal, roughness y metallic como PNG, o exporta la malla texturizada como GLB, FBX, OBJ o un archivo listo para Roblox.

Preguntas sobre el generador de normal map

¿Qué hace exactamente un generador de normal map?

Analiza el sombreado y el detalle de una imagen o malla y codifica la dirección de la superficie en una textura RGB. Los motores de juego usan ese mapa para simular relieves, ranuras y bordes sin añadir polígonos.

¿Este generador de normal map es gratis?

Puedes generar modelos y previsualizar texturas en el plan gratuito. Las texturas PBR en 4K con mapas normal, roughness y metallic forman parte de los planes de pago, que empiezan en unos pocos dólares al mes.

¿Puedo obtener un normal map a partir de una sola foto?

Sí. Una foto plana de ladrillo, madera, tela o metal basta para producir un normal map utilizable. Para mejores resultados, usa iluminación uniforme y un ángulo frontal.

¿Cómo funciona el generador de texto 3D?

Describes lo que quieres, por ejemplo un logotipo cromado con bordes redondeados, y el modelo genera una malla texturizada a partir de ese texto. Después puedes generar un normal map para ella o exportarla directamente.

¿La exportación de Roblox mesh funciona en Roblox Studio?

Sí. La exportación mantiene el número de triángulos dentro de los límites de Roblox y empaqueta las texturas para que la malla se importe a través del gestor de assets sin limpieza manual.

¿Qué formatos puedo descargar?

Las texturas se exportan como PNG. Los modelos se exportan como GLB, FBX, OBJ, USDZ y STL, con los mapas PBR incluidos cuando el formato lo permite.
