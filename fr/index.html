Comment générer une normal map

  1. Importez ou générez
    Importez une image de texture ou une photo, ou saisissez un prompt pour créer un modèle 3D à partir de texte. Les deux partent du même écran.
  2. Choisissez la résolution de texture
    Prenez 1K pour les aperçus ou jusqu'à des textures PBR 4K pour les assets principaux. Le générateur de normal map tourne dans le cloud, il n'y a donc rien à installer.
  3. Téléchargez les maps ou le modèle entier
    Récupérez les maps normal, roughness et metallic en PNG, ou exportez le maillage texturé en GLB, FBX, OBJ ou en fichier prêt pour Roblox.

Questions sur le générateur de normal map

Que fait concrètement un générateur de normal map ?

Il analyse l'ombrage et les détails d'une image ou d'un maillage et encode l'orientation de la surface dans une texture RGB. Les moteurs de jeu utilisent cette map pour simuler bosses, rainures et arêtes sans ajouter de polygones.

Ce générateur de normal map est-il gratuit ?

Vous pouvez générer des modèles et prévisualiser les textures dans l'offre gratuite. Les textures PBR 4K avec normal, roughness et metallic font partie des formules payantes, qui démarrent à quelques dollars par mois.

Puis-je obtenir une normal map à partir d'une seule photo ?

Oui. Une photo à plat de brique, de bois, de tissu ou de métal suffit pour produire une normal map exploitable. Pour de meilleurs résultats, utilisez un éclairage uniforme et un angle de face.

Comment fonctionne le générateur de texte 3D ?

Vous décrivez ce que vous voulez, par exemple un logo chromé aux bords arrondis, et le modèle génère un maillage texturé à partir de ce texte. Vous pouvez ensuite générer une normal map pour ce maillage ou l'exporter directement.

L'export Roblox mesh fonctionne-t-il dans Roblox Studio ?

Oui. L'export maintient le nombre de triangles dans les limites de Roblox et embarque les textures pour que le maillage s'importe via le gestionnaire d'assets sans nettoyage manuel.

Quels formats puis-je télécharger ?

Les textures s'exportent en PNG. Les modèles s'exportent en GLB, FBX, OBJ, USDZ et STL, avec les maps PBR incluses lorsque le format le permet.
