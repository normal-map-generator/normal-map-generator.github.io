Warum dieser Normal Map Generator

Komplettes PBR-Set, nicht nur die Normal Map

Ein Durchlauf liefert die Normal Map zusammen mit Diffuse-, Roughness- und Metallic-Map, sodass das Material ohne zusätzliches Baking direkt in Blender, Unity, Unreal oder Godot landet.

Funktioniert mit Foto, Kachel oder generiertem Modell

Geben Sie eine gescannte Oberfläche, eine nahtlose Textur oder ein aus einem Bild erzeugtes Mesh hinein, und der Normal Map Generator leitet Oberflächendetails ab, die zur Geometrie passen.

3D-Text-Generator inklusive

Tippen Sie einen Prompt, um aus einer Beschreibung ein texturiertes 3D-Modell zu bauen, und erstellen Sie im selben Projekt die Normal Maps dafür. Praktisch für Logos, Beschilderung und Spiel-Props.

Roblox-Mesh und Game-Engine-Export

Download als GLB, FBX oder OBJ mit gepackten Texturen, einschließlich eines optimierten Roblox-Mesh mit einem Polygonbudget, das sauber in Roblox Studio importiert wird.

So erstellen Sie eine Normal Map

  1. Hochladen oder generieren
    Laden Sie ein Texturbild oder Foto hoch, oder tippen Sie einen Prompt, um ein 3D-Modell aus Text zu erzeugen. Beides beginnt auf demselben Bildschirm.
  2. Texturauflösung wählen
    Wählen Sie 1K für Vorschauen oder bis zu 4K-PBR-Texturen für Hero-Assets. Der Normal Map Generator läuft in der Cloud, es muss also nichts installiert werden.
  3. Maps oder das ganze Modell herunterladen
    Holen Sie sich Normal-, Roughness- und Metallic-Map als PNG oder exportieren Sie das texturierte Mesh als GLB, FBX, OBJ oder als Roblox-fertige Datei.

Fragen zum Normal Map Generator

Was macht ein Normal Map Generator eigentlich?

Er analysiert Schattierung und Details in einem Bild oder Mesh und kodiert die Oberflächenrichtung in eine RGB-Textur. Game-Engines nutzen diese Map, um Erhebungen, Rillen und Kanten vorzutäuschen, ohne Polygone hinzuzufügen.

Ist dieser Normal Map Generator kostenlos?

Im kostenlosen Tarif können Sie Modelle erzeugen und Texturen in der Vorschau ansehen. 4K-PBR-Texturen mit Normal-, Roughness- und Metallic-Maps gehören zu den bezahlten Tarifen, die bei wenigen Dollar im Monat beginnen.

Kann ich aus einem einzelnen Foto eine Normal Map bekommen?

Ja. Ein flaches Foto von Ziegel, Holz, Stoff oder Metall reicht für eine brauchbare Normal Map. Die besten Ergebnisse erzielen Sie mit gleichmäßiger Beleuchtung und frontalem Winkel.

Wie funktioniert der 3D-Text-Generator?

Sie beschreiben, was Sie möchten, zum Beispiel ein Chrom-Logo mit abgerundeten Kanten, und das Modell erzeugt aus diesem Text ein texturiertes Mesh. Anschließend können Sie eine Normal Map dafür erstellen oder es direkt exportieren.

Funktioniert der Roblox-Mesh-Export in Roblox Studio?

Ja. Der Export hält die Dreieckszahl innerhalb der Roblox-Grenzen und packt die Texturen so, dass das Mesh ohne manuelle Nacharbeit über den Asset-Manager importiert wird.

Welche Formate kann ich herunterladen?

Texturen werden als PNG exportiert. Modelle exportieren Sie als GLB, FBX, OBJ, USDZ und STL, mit PBR-Maps, sofern das Format sie unterstützt.
