Por que usar este gerador de normal map

Em uma única passada você recebe o normal map junto com os mapas diffuse, roughness e metallic, então o material entra direto no Blender, Unity, Unreal ou Godot sem bake extra.

Funciona a partir de foto, tile ou modelo gerado

Digite um prompt para criar um modelo 3D texturizado a partir de uma descrição e gere os normal maps dele no mesmo projeto. Útil para logotipos, placas e props de jogos.

Exportação para Roblox mesh e game engines

Como gerar um normal map

  1. Envie ou gere
    Envie uma imagem de textura ou foto, ou digite um prompt para criar um modelo 3D a partir de texto. As duas opções começam na mesma tela.
  2. Escolha a resolução da textura
    Use 1K para prévias ou até texturas PBR em 4K para assets principais. O gerador de normal map roda na nuvem, então não há nada para instalar.
  3. Baixe os mapas ou o modelo inteiro
    Pegue os mapas normal, roughness e metallic em PNG, ou exporte a malha texturizada como GLB, FBX, OBJ ou um arquivo pronto para Roblox.

Perguntas sobre o gerador de normal map

O que um gerador de normal map faz de fato?

Ele analisa o sombreamento e os detalhes de uma imagem ou malha e codifica a direção da superfície em uma textura RGB. As game engines usam esse mapa para simular relevos, sulcos e bordas sem adicionar polígonos.

Este gerador de normal map é gratuito?

Você pode gerar modelos e visualizar texturas no plano gratuito. Texturas PBR em 4K com mapas normal, roughness e metallic fazem parte dos planos pagos, que começam em poucos dólares por mês.

Consigo um normal map a partir de uma única foto?

Sim. Uma foto plana de tijolo, madeira, tecido ou metal já basta para produzir um normal map utilizável. Para melhores resultados, use iluminação uniforme e ângulo frontal.

Como funciona o gerador de texto 3D?

Você descreve o que quer, por exemplo um logotipo cromado com bordas arredondadas, e o modelo gera uma malha texturizada a partir desse texto. Depois é possível gerar um normal map para ela ou exportá-la diretamente.

A exportação de Roblox mesh funciona no Roblox Studio?

Sim. A exportação mantém a contagem de triângulos dentro dos limites do Roblox e empacota as texturas para que a malha seja importada pelo gerenciador de assets sem limpeza manual.

Quais formatos posso baixar?

As texturas são exportadas em PNG. Os modelos saem em GLB, FBX, OBJ, USDZ e STL, com os mapas PBR incluídos quando o formato suporta.
